# 프로젝트 전체 이력 — 2026-10-10

## 기록을 읽는 기준

이 문서는 2026-09-08~2026-10-10의 현재 프로젝트 대화와 실제 파일을 대조한 기록이다. 이번 문서화 요청 이전의 사용자 메시지 179건, 최종 답변 129건, 진행 안내 182건, 합계 490건을 정제해 보존했다. 내부 추론·도구 원문·비밀번호·인증키는 공유하지 않는다. '생각 과정'은 대화와 설계서에 명시된 결정 근거, 대안, 결과와 한계로 정리한다.

관련성이 의심되는 다른 보고서/PBL 대화도 확인했으나 로봇·센서 활동이어서 이 프로젝트 이력에 섞지 않았다. 원본 첨부 이미지의 모든 픽셀과 삭제된 다른 채팅까지 복원한 자료는 아니다. 대화에서 파일이 존재한다고 말한 것과 이번에 실제 존재/내용을 확인한 것은 구분한다.

근거 우선순위는 현재 코드·실제 실행 결과 → 해당 시점 검증 문서 → 사용자에게 전달한 답변 → 초기 계획이다. 예전 문서의 '미연결', '아직 학습 안 함'은 작성 당시 상태이며 최신 상태가 아니다. 날짜는 KST 기준이다. 파일명 안의 `...Z`는 UTC 실행 시각이다.

## 최초 계획과 목표

초기 통합 실행가이드의 기준일은 2026-09-02이며 13주·91시간 프로젝트로 작성됐다. 목표는 허가된 영상에서 불꽃·연기를 탐지하고, 의심 사건을 만든 뒤 기상·지형·산림 조건을 결합해 예상 확산 영역을 지도에 보여주는 연구용 서비스였다. 대피 경로와 전국 규모 감시는 확장 목표였다.

### 8. 2026-10-09 — 네이버 지도, ITS, 상시 분석

- 사용자가 등고선/숲만 보이는 지도를 어려워해 Naver Dynamic Map의 일반·위성/하이브리드 배경을 추가했다. 주소로 발화점을 선택하고 좌표의 주소를 확인하기 위해 Geocoding/Reverse Geocoding도 추가했다. MapLibre 로컬 GIS/PNG 기능은 보존했다.
- 네이버 JS ID는 브라우저 공개 식별자, Secret은 서버 전용으로 분리했다. 지도가 선명해져도 DEM 해상도와 확산 정확도는 높아지지 않는다.
- ITS 고속도로 HTTPS HLS 대구 주변 목록 216건과 안심 CCTV 브라우저 재생을 확인했다. 모든 지점의 성공을 뜻하지 않는다. UTIC는 신청 후 승인 대기이며 미연결이다.
- 초기 브라우저 선택 영상 분석은 최대 2분이었다. 사용자는 화면을 선택하지 않아도 모든 등록 CCTV에서 서버 감지를 원해 별도 supervisor/HLS 수집/공간·시간 게이트를 만들었다. 한도 4대는 실제 감시 대수와 다른 값이다.
- 화면–지도 보정과 자동 확산 조건, 제외 구역·정답 검토 기록, 실제 사건 평가 도구, DEM 복수 타일 지원을 구현했다. 실제 카메라 보정 자료는 없어 자동 위치/확산은 OFF다.
- 승인 여부가 불명확할 때 실제 공공 영상 감시는 OFF로 유지했다. 사용자에게 AI 분석·이미지 저장 허용을 확인했다는 답변을 받은 뒤 시간 제한 실제 시험을 시작했다. 다른 사람의 게시판 답변을 본 프로젝트의 승인서로 대체하지 않았다.
- 4대 시험 기록, 자동 종료, 사진 만료 처리, 요청/프레임/정체/간격 지표를 추가했다. 1시간 시험은 403으로 간헐 수신되어 안정 연결 실패였다. 상세 수치는 CCTV 문서를 참고한다.
- 공식 HLS의 제한된 동일 호스트 redirect, 최종 playlist 기준 상대 경로, 승인 media playlist 재사용을 수정했지만 403의 기관 내부 원인은 확정하지 못했다. 인증 제한을 우회하지 않았다.
- 10-09 서비스 공개 저장소 `200-Pro/fire-detection`을 생성하고 최초 소스·테스트·문서 105파일을 게시했다. 첫 서비스 commit은 `84192e1`이다. 배포는 아니며 모델/키/DB/GIS/영상은 제외했다.

### 9. 2026-10-10 — 카메라 UI·연기 알람·제거·세션 복구

- 우선순위를 CCTV 연결/영상 표시로 확정했다. 실제 인증 해제 대신 기존 계정 인증을 유지하고 일시 서버 장애 시 세션 복구를 재시도했다. 비밀번호를 코드에 넣지 않았다.
- 카메라 카드의 최근 정지 프레임과 선택 카메라 HLS 플레이어를 분리했다. 새 후보 알람에서 해당 카메라 화면을 열고, 브라우저별 자동 열기는 기본 OFF로 추가했다. 수천 개 스트림을 화면에 모두 재생하는 방식은 아니다.

- fire 외 smoke도 지속 후보 알람을 만들도록 추가했다. 동시 후보에서는 fire 우선이며 연기 점수 0.5 규칙은 초기 연구값이다.
- 401/403/429 대기·Retry-After·수집 단계 진단·새 작업자 세션 캐시 초기화를 보완했다. 실제 짧은 진단 72프레임, 서비스 2분 시험 48프레임에서 오류 0회를 확인했다. 장시간 403 해결 완료는 아니다.

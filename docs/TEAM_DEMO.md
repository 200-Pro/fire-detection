# 팀 시연 순서 — 탐지부터 확산까지

프로젝트는 `D:\fire-dettection`입니다. 현재는 실제 YOLO11n으로 불꽃·연기 후보를 찾는 로컬 데모와, 직접 지정한 가상 발화점에서 수행하는 연구용 확산 시뮬레이션입니다. YOLO를 새로 학습하거나 Colab을 켤 필요는 없습니다.

## 1. 서버와 화면

```powershell
& "D:\fire-dettection\scripts\start-local.ps1" -NoBrowser
```

PC에서 `http://localhost:5173/`에 접속해 기존 계정으로 로그인합니다. 중지는 `D:\fire-dettection\scripts\stop-local.ps1`입니다. DB·증거 사진·학습 모델·GIS 원본은 보존됩니다. 휴대폰에서 localhost는 휴대폰 자신을 뜻하므로 PC 주소 대신 사용할 수 없습니다.

## 2. 3분 시연

1. 모니터링 개요의 **예제 테스트**에서 불꽃 예제를 실행합니다. 단순 강제 알림이 아니라 기존 best.pt 추론과 지속 감지 정책을 거칩니다. 예제 알람은 DEMO로 구분됩니다.
2. 도착한 알람의 **자세히**에서 증거 사진, 모델 후보 점수, 모델/정책 해시를 확인합니다. 점수는 실제 화재 확률이 아닙니다.
3. **발화점 지정·확산 실험**을 누릅니다. 알람 ID가 새 계산과 연결될 뿐 영상에서 실제 발화 위경도를 알아낸 것은 아닙니다.
4. **검증된 숲 격자 지점으로 초기화** → 수동 가상 기상 → CA → 30모델분 → 반복 30회 → seed 42를 선택합니다.
5. 연구용 가상 발화점 확인란을 체크하고 실행합니다. 실제 사건 위치를 확인했다는 의미가 아닙니다.
6. 완료 후 10/30분 도형과 평균 면적, **저장된 연결 알람**을 확인합니다. 시간은 보정되지 않은 모델 시간이지 실제 도달시간이 아닙니다.
7. GeoJSON과 PNG를 저장합니다. GeoJSON에 입력·seed·자료/엔진 해시와 연결 ID가 포함됩니다. 최근 이력에서 다시 열 수 있습니다.
8. 기상청 모드로 바꾸고 실황 기준시각·풍향·풍속 등을 확인해 새 계산을 실행합니다. 조회 실패·오래된 자료면 실행을 차단하며 수동 값으로 몰래 대체하지 않습니다.

산불위험지수는 대구 전체의 별도 참고 정보입니다. 실제 화재 확률이 아니고 확산 속도에 적용하지 않았습니다. 회색 지도·자료 밖은 미확인 영역이며 안전 구역이 아닙니다.

## 3. 두 명의 역할

- 관제 담당: PC 로그인, 알람 증거 확인, 가상 발화점 지정, 실험 실행·기록.
- 카메라 담당: Android/iPhone에서 연결 코드 입력, 본인이 HTTPS 신뢰·카메라 권한 승인, 영상 전송. 자세한 절차는 `docs/PHONE_TEST.md`를 따릅니다.
- 실제 휴대폰의 LAN 접속·인증서 신뢰·방화벽·카메라 동작은 사용자 기기에서 별도 검증해야 합니다. publisher API 자동 테스트 통과가 실제 휴대폰 검증 완료를 뜻하지 않습니다.
- 안전을 위해 실제 불을 만들지 말고 이미 확보한 이미지/영상 등 안전한 자료를 사용합니다. 화면을 재촬영한 시연은 실제 야외 CCTV 성능 검증과 구분합니다.

## 4. 공유할 것 / 공유하지 않을 것

코드·설명·비밀정보 없는 실험 결과를 공유합니다. 다른 PC는 가상환경과 node_modules를 복사하지 말고 설치 안내대로 다시 준비합니다. 모델/정책과 필요한 전처리 자료 사본도 준비해야 합니다.

`.env`, 인증키, 비밀번호, 실제 사건 사진, runtime DB와 사용자 세션은 함부로 공유하지 않습니다. 기상 API 키는 서버에서만 사용합니다. 지도 원본의 사용 조건도 지킵니다.

## 5. 문제가 생겼을 때

- 발화점이 숲 격자 밖: 검증된 숲 지점으로 초기화하고 확인란을 다시 체크합니다.
- 실황 오류: 최신 자료·API 승인·서버 키를 확인하거나, 수동 가상 시나리오임을 명시하고 전환합니다.
- 대기열 가득 참: 진행 중 작업 완료 후 재실행합니다. 여러 번 연속 클릭하지 않습니다.
- 재시작 뒤 작업 실패: 미완료 작업은 자동 재개하지 않습니다. 저장된 조건으로 새 계산을 실행합니다.
- 옛 결과가 보임: 설정을 바꾸는 것만으로 기존 결과가 바뀌지 않습니다. 새 계산하거나 원하는 이력을 선택합니다.

상세 원리·제한은 `docs/SPREAD_GUIDE.md`, 비교 결과는 `docs/SPREAD_EXPERIMENTS.md`, 실제 점검 범위는 `docs/VERIFICATION.md`를 참고합니다. Docker/AWS 공개 배포와 실제 산불 확산 정확도 검증은 이번 완료 범위에 포함되지 않습니다.
